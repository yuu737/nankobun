# それって身近なもの何個分？（試作）

東京ドーム、自分の家、いつもの道。PLATEAU のデータをもとに、身近なもので比べる。

**動かす：https://yuu737.github.io/nankobun/**（パソコンの Chrome・Edge を推奨。スマホでも軽い表示で動く）

PLATEAU の建物を、**PLATEAU 基準の東京ドーム**で測る。建物をクリックすると、その数だけドームが空から降ってきて積み上がる。1 個に満たない分は、最後のドームを切り落とす（切り口は赤）。結果の札で「縮める」にも切り替えられる。

## できること
- **測る**：建物をクリック（または左上の欄に名前を入れる）。左下で「高さ・面積（足元）・体積・駅までの距離」を切り替える
- **物差しを変える**：札の「この建物を物差しにする」で、その建物が物差しになる（戸建ては「軒」、ほかは「棟」で数える）
- **駅までの距離**：選んだ建物の端から駅までの直線を、物差しを倒して並べて数える（道なりではない）
- **町ごと**：町丁目の名前（例「文京区後楽一丁目」）で、その町の建物の体積・足元の面積を全部足して比べる
- **道をなぞる**：真上からの地図で道に沿って点を打ち、その長さを測る。「この道を物差しにする」で「いつもの道」が物差しになる
- **タワーと比べる**：検索欄に「スカイツリー」「東京タワー」。どちらも読み込んだ範囲の外なので、高さは公式の値（634 m・333 m）を使い、形は見た目のための簡単な模型
- **一言**：結果の文をコピー、または数字と文を描き込んだ画像を保存
- 操作：ドラッグで見回す、W A S D で歩く（Shift で速く）、Esc で比べるのをやめる

## 物差し（PLATEAU 基準の東京ドーム）
| | PLATEAU（`東京ドームシティー`、LOD1） | 公式（東京ドームシティのサイト） |
|---|---|---|
| 高さ | 計測高さ 54.8 m | 最高部 56.19 m |
| 面積 | 足元の外形 34,564 m² | 建築面積 46,755 m² |
| 体積 | LOD1 の箱 145.2 万 m³ | 容積 約 124 万 m³ |

比べる相手の建物も同じ物差し（高さは計測高さ、面積は足元の外形、体積は LOD2 があれば屋根の下を足し上げ、無ければ LOD1 の箱）で数える。

## 分かっている弱点
- LOD2 の無い塔は、PLATEAU の LOD1 の箱が低層部の高さになる。見た目のためだけに、外形を内側に縮めた仮の塔を計測高さまで立てている（20 棟、札に断り書き）。体積は LOD1 の箱のまま
- 外壁は用途・階数から描いた絵で、実物の外観ではない。車道の白線・横断歩道・看板は推定や飾り
- 東京スカイツリー・東京タワーの形はおおよその模型。高い塔を画面に収めると、読み込んだ範囲の端が見える
- 範囲は東京ドームを中心に東西南北 1.4 km（文京区・千代田区の一部）だけ
